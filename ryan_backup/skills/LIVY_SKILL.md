# LIVY SKILL — Editor

Quality gates. Determines what's ready to publish.

## What She Does

Reviews Raj's SEO draft for:
- Grammar and spelling
- Readability
- AdSense policy compliance
- Overall quality
- Fact accuracy

## Quality Checklist

- [ ] No grammar errors
- [ ] Readable (no Flesch-Kincaid warnings)
- [ ] Original content (no plagiarism)
- [ ] Meets AdSense policies
- [ ] All facts verified
- [ ] Images have alt text
- [ ] Links work

## Output Options

- **Publish-ready** — Approved, Ken publishes
- **Feedback** — Needs revision, returns to Elena or Raj

## Integration

- Publish-ready → Ken for WordPress
- Feedback → Back to appropriate agent with notes
