# RAJ SKILL — SEO Optimizer

Optimizes content for search engines.

## What He Does

Takes Elena's human draft and:
- Adds target keywords naturally
- Optimizes headers (H1, H2, H3)
- Adds internal links
- Improves meta description
- Checks readability

## SEO Requirements

- Keyword in title
- Keyword in first 100 words
- Keyword in at least one H2
- 1-2% keyword density
- Readable (Grade 8 or below)
- 1000+ words for recipes

## Input

- Human draft from Elena
- Target keywords

## Output

- SEO-ready draft
- Meta description
- Internal link suggestions

## Integration

- Output goes to Livy for editing
- Tracks in pipeline status
